# Revisit website

Marketing site for **Revisit**: AI-powered customer retention for restaurants.

> Bring your customers back. Automatically.

The entire site is one file, `index.html`. Styles, scripts, product screenshots and customer logos are all built in, so there is nothing else to upload.

## Live site

Hosted on GitHub Pages: https://jacobbweng.github.io/revisit/

## Making changes

- **Business email:** in `index.html`, search for `CONFIG` near the bottom and change the email there. Also replace the address where it appears as plain text.
- **Contact form:** it shows a thank-you message but doesn't send anything yet. To receive submissions, connect a form service like Formspree.
